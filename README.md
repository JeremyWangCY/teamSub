# TeamsSub

Windows 桌面实时字幕阅读与中英互译工具。

通过 Windows UI Automation 读取 Teams／飞书**已经显示在屏幕上**的实时字幕，不截图、不 OCR、不修改会议客户端本体。字幕可以搜索、按发言人筛选，也可以按会议主题做中英互译，并导出为 Markdown 或双语 SRT。

## 功能

- **实时字幕阅读**：直接读取会议客户端无障碍树里的字幕节点，延迟取决于客户端刷新，通常在 1 秒以内。
- **中英互译**：按主题（领域说明 + 译名对照）约束译文，支持上文语境、人工修正回写、译文质检（数字／单位／术语／漏译）；思考强度可选自动／关／低／中／高，设置里的「检测」可一键探测上游实际接受哪个参数。
- **碎句合并**：会议客户端按显示行下发字幕，一句话常被切成两三行、同一行还会先出半句再补全。采集层会按「同一人 + 间隔短 + 上一条没收到句末标点」把续写折成一条，改写则就地替换，读起来是一句完整的话。
- **悬浮字幕条**：无边框圆角小窗，可拖动缩放，最小化主窗口时自动切到它，会议中不占地方；上方用浅色保留上一句当语境，断行按中文禁则排（标点不占行首、西文词不拆）。
- **历史会议**：每场会议独立成文件，可浏览、重命名、编辑原文和译文、续接、多选合并导出；删除会移入系统回收站，可还原。
- **记录补译**：在会议记录里补译缺失内容，查看处理进度、已保存和失败条数；译文写回记录，取消或切换页面后已完成内容仍保留。
- **复制**：正文右键可复制选中／全选／全部，Ctrl+C 同样可用。
- **界面细节**：浅色／暗色统一表面层次，输入框使用内嵌双环聚焦；配置下拉支持长名称省略和键盘操作，API Key 可切换显示／隐藏。复制反馈 2.5 秒后淡出，拖动滚动条查看旧字幕时暂停跟随，点击「回到底部」恢复。
- **系统托盘**：关闭主窗口时收进托盘并继续采集、翻译；最小化时保留任务栏入口。托盘图标可唤回窗口，托盘或更多菜单中的「退出 TeamsSub」才会结束程序。托盘不可用时，关闭键退回最小化到任务栏。
- **导出**：Markdown、SRT 字幕、纯文本，导出用快照，不受当前搜索／筛选影响。
- **导出内容**：可选原文、译文或对照；补译完成后直接从会议记录导出。
- **应用更新**：设置 → 更新，检查正式版、查看下载进度、取消或重试；校验通过后保存会议、安装并重启。

## 安装与启动

需要 Windows 10/11（x64）。普通用户可从 [GitHub Releases](https://github.com/JeremyWangCY/teamsSub/releases/latest) 下载 `TeamsSub-Setup-版本号.exe`，无需 Python 或管理员权限。安装程序提供开始菜单入口和可选桌面快捷方式。

默认安装目录为 `%USERPROFILE%\Apps\TeamsSub`。已有自动更新功能的版本可在设置 → 更新中下载并更新；旧版首次升级需要从系统托盘退出后覆盖安装。配置和会议记录会保留，卸载不会主动删除用户数据。便携版 ZIP 解压到固定可写目录后启动 `TeamsSub.exe`。兼容性实测范围见 [兼容性说明](docs/COMPATIBILITY.md)。

源码运行需要 Python 3.12 及可用的 Tkinter：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.bat
```

排查启动问题时用 `debug.bat`，它会保留控制台输出。

## 打包成单个 exe

装了 PyInstaller 后直接运行 `build_exe.bat`，产物在 `dist\TeamsSub.exe`（约 25 MB，无需安装 Python）。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\build_exe.bat
```

打包脚本结束时打印产物 SHA256，便于核对。exe 带版本元数据（属性 → 详细信息里能看到产品名与版本）。

安装 [Inno Setup](https://jrsoftware.org/isinfo.php) 后，运行以下命令生成安装包。安装包采用文件白名单，只包含应用程序和许可证。

```powershell
.\build_installer.ps1 -IsccPath 'C:\Program Files\Inno Setup 7\ISCC.exe'
```

Release 中提供 `SHA256SUMS.txt`，可使用 `Get-FileHash 文件名 -Algorithm SHA256` 核对下载文件。

单文件模式首次启动会先解压到临时目录（约 2–5 秒），之后快一些。**配置、会议记录、日志都保存在 exe 同目录**，所以要给它一个固定的文件夹，不要放在临时目录里跑。

## 使用

1. 在会议客户端里先打开实时字幕（Teams：更多 → 语言和语音 → 打开实时字幕）。
2. 启动 TeamsSub，选择对应的会议模式。
3. 翻译默认关闭。在「设置 → 服务」里填引擎、地址、模型和密钥后即可开启。
4. 「思考强度」在「设置 → 服务」，默认 `自动`（不改动请求）。选关／低／中／高后，程序按候选字段顺序试探上游，被「不认识这个参数」拒绝就换下一个；点旁边的「检测」可先把实际可用的字段记进配置，之后不再重复试探。

## 保存与数据位置

默认数据放在程序目录：`appconfig.json` 保存设置，`captions/` 保存会议记录。也可以在启动前设置 `TEAMSSUB_DATA_DIR` 指向别处。

每场会议生成唯一文件名，自动保存为 SQLite（结构化事实源）+ Markdown（可读投影）。记录按 ID 更新，Markdown 用临时文件原子替换。**不要在程序正在使用某场会议时删除或编辑它的数据库**——SQLite 是恢复依据。

## 隐私与数据

- 本工具读取的是**屏幕上已经显示**的字幕，不录音、不截屏、不触碰会议音频。
- 会议记录只保存在本机。
- **开启翻译后**，字幕原文与所配置的上文会发送到你自己填写的翻译服务。是否开启、发给谁，完全由你决定。
- API 密钥用 Windows DPAPI 加密后存在本机配置里，换机器或换 Windows 账户都解不开。
- 不要把自己的 `appconfig.json`、`cache/`、`captions/` 提交到任何公开仓库。
- 更新检查与下载只向 GitHub 的公开 Release API 和官方资源域名发送请求，不读取或发送翻译配置、API Key 和会议记录。

## 已知限制

- 依赖会议客户端的无障碍树结构。**客户端升级后控件类名可能变化**，届时需要更新对应的读取实现；升级后建议先确认字幕仍能被读到。
- 只读取客户端已经渲染出来的字幕，客户端不显示的内容读不到。
- 翻译质量取决于所选模型与主题描述，离线测试无法代替真实会议验收。

## 版本

当前版本 v0.1.13。程序内「帮助」页和设置 → 更新均显示版本号。自动更新与失败恢复策略见 [更新说明](docs/UPDATING.md)。

主界面「翻译主题」选择器常驻显示当前主题，选择后立即保存并用于后续翻译，重启后仍保留；已完成的译文保留。设置页浏览其他主题属于草稿，点击保存才切换。长名称可悬停查看全称。

「译名对照」按每行 `原文=译文` 填写。OpenAI 兼容引擎会将当前主题的会议背景和译名对照放入每次翻译请求的 system 提示词；模型优先采用对应译名，同时结合句意判断。这属于推理时提供上下文，不会训练模型。当前 DeepL、Azure 适配器未接入这两项。
