# TeamsSub 0.1.12

本版包含此前尚未发布的桌面界面、主题选择、配置管理及悬浮窗优化。

- 主界面常驻翻译主题选择器，切换立即保存，重启后保留；设置草稿与已生效主题分别显示。
- 保存多个引擎配置，支持新建、重命名、删除和切换；API Key 可显示或隐藏，切换配置后恢复遮罩。
- 会议记录补译显示进度，译文保存回记录；导出可选原文、译文或对照。
- 关闭主窗口到托盘，最小化到任务栏；圆角悬浮窗、明暗主题、输入聚焦、长名称与阅读位置保护。
- 设置 → 更新为独立更新页，显示当前版本与「检查更新」；删除「备用」页，保留已有本地配置。
- 历史列表与会议详情支持重命名（列表可按 F2）；标题同步到记录与导出，文件路径和记录 ID 保留。
- 会议详情明确提供「编辑记录」，可逐条修改发言人、原文和译文，保存后重新打开、导出均保留。修复编辑页发言人标签与输入框重叠。
- 悬浮窗说话人圆点采用内缩留白与抗锯齿绘制，避免边缘裁切。
- 修复退出时取消子控件定时器导致 Tcl 回调重复释放、窗口未彻底销毁的问题。

发布文件：Windows x64 安装包、便携版 ZIP、SHA256SUMS.txt。安装包无需管理员权限，默认安装至当前用户的 Apps/TeamsSub；升级和卸载不主动删除配置、会议记录。安装包与应用暂未使用代码签名证书签名。

隐私：发布文件使用明确白名单生成，不包含本机配置、密钥、缓存、日志或会议记录。更新检查仅请求公开版本信息，不使用翻译密钥、不发送会议内容、不自动执行安装程序。

开发验证：37 项桌面回归脚本、15 项更新、会议编辑与退出专项测试通过；源码与 Git 历史扫描未发现泄漏，已将打包内容与本机凭据做本地比对并验证源码一致性。使用独立安装 ID 和互斥量的安装测试验证了安装、覆盖升级、卸载保留配置与会议记录；正式安装包验证了程序运行时拒绝覆盖。真实会议采集与在线翻译质量仍取决于会议客户端和配置的引擎。
