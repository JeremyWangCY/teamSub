# TeamsSub 0.1.13

- 设置中的独立更新页支持下载进度、取消及重试；校验后自动保存、安装并重启，原理说明放入文档。
- 安装前备份旧程序，安装失败或新版无法启动时尝试恢复；安装器等待旧进程退出后才覆盖。
- 修复临时数据库写入失败后遗漏批次的问题：保留待写记录并合并较新编辑，保存完整后才允许更新。
- 保留历史会议重命名、记录编辑与导出，以及悬浮窗完整圆点修复。
- 初始窗口根据桌面工作区收紧，避免任务栏遮住底部；停止自动清理全局 PyInstaller 临时目录，避免误删其他应用资源。
- 提供不读取用户配置的离线运行诊断入口，检查打包依赖、中文路径、记录及导出。

首次从旧版升级请退出托盘中的 TeamsSub 后覆盖安装。配置和会议记录保留。

支持范围和实际测试范围见 [兼容性说明](COMPATIBILITY.md)，更新恢复边界见 [更新说明](UPDATING.md)。
