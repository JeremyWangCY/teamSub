# TeamsSub 0.1.14

- 历史会议列表页新增“打开记录文件夹”，无需选择会议即可打开实际保存位置；目录不存在时自动创建，打开失败时显示提示。
- 合并同一发言人的碎句与续写，重发改写就地替换；悬浮窗改善中文断行并保留上一句上下文。
- 修复上一句译文异步返回或人工修正后，悬浮窗未及时刷新的问题。
- OpenAI 兼容引擎新增思考强度选项及参数检测。

安装：下载 `TeamsSub-Setup-0.1.14.exe` 并运行，或在“设置 → 更新”选择“下载并更新”。更新保留配置与会议记录。便携版请解压到固定可写目录。

验证：93 项测试及冻结程序 8 项离线自检通过。真实 Windows 10、高 DPI/多显示器、Azure 思考强度及跨产品时间戳对齐尚未完成验证或接入，详情见兼容性说明。
