# TeamsSub 0.1.15

- 历史会议列表与删除确认框都显示**开始时间、条数、时长**：自动命名的会议常常全叫「飞书会议」，
  以前几场同名会议在界面上长得一模一样，删除时无从分辨。现在按「2026-10-30 13:12 · 飞书会议 ·
  5 条 · 12 分钟」显示，搜索也可以直接匹配日期。
- 删除确认框逐场列出所选会议，并写明删掉几场、记录会进回收站。
- 修复历史会议删不掉：以前整批文件走一次回收站调用，只要一个文件被占用或权限不足，整批都返回失败，
  界面只闪一句错误码。现在逐场删除，能删的照删，删不掉的单独说明是哪一场、为什么（被占用／拒绝访问／
  只读等），不再出现「点了没反应」。
- 支持删除正在记录的那场会议：先停止采集、把未写入的字幕落盘、关闭写线程，再移入回收站；之后的新字幕
  自动记到一场新会议，不会写回已删文件。
- 删除结果在列表刷新后仍然可见，不再被「N 场」覆盖。

安装：下载 `TeamsSub-Setup-0.1.15.exe` 并运行，或在“设置 → 更新”选择“下载并更新”。更新保留配置与会议记录。便携版请解压到固定可写目录。

验证：112 项测试通过（新增 `tests/test_meeting_delete.py` 19 项，覆盖时间显示、时长格式化、逐场删除、
占用失败隔离与正在记录会话的安全删除）。安装包未生成本版本（本机无 Inno Setup）；`dist\TeamsSub.exe`
可校验版本 0.1.15 与 SHA256。真实 Windows 10、高 DPI/多显示器尚未复验，详情见兼容性说明。
