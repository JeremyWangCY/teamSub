# TeamSub 0.2.0

- **改名 TeamSub**：窗口、托盘、安装包（`TeamSub-Setup-0.2.0.exe`）、程序文件（`TeamSub.exe`）和 GitHub 仓库
  （`JeremyWangCY/teamSub`）统一使用新名字。环境变量改为 `TEAMSUB_DATA_DIR` / `TEAMSUB_UI_SCALE`。
- **高分屏适配**：启动时声明 DPI 感知并按屏幕缩放，125%／150% 下文字、圆角和图标都按物理像素绘制，不再整体拉伸发虚。
- **统一图标与页面外壳**：导航带品牌标、图标和版本号；历史、设置、帮助覆盖整个右侧，去掉重复标题和说明性文案，
  非内容页一屏放下。新应用图标，托盘小尺寸单独优化。
- **历史会议**：列表改为两行布局（标题；日期 · 条数 · 时长），文件编号靠右，支持点击、Ctrl、Shift 和键盘选择；
  场次统计移到搜索行末尾。
- **跟随主题的对话框**：重命名会议、新建／重命名配置不再弹系统样式输入框；导出选项改用自绘复选框。
- **设置页按钮**：配置的新建／重命名／删除、主题工具栏（原来的「+」字符改为图标）、检测、检查更新、测试、保存
  都配上统一图标，删除使用危险色。
- 新快捷键：Ctrl+1 实时会议、Ctrl+2 历史会议、Ctrl+, 设置、F1 帮助。
- 修复：启动后很快有字幕写入时，会把本次会话误报为「上次会议没有正常结束」。

安装：下载 `TeamSub-Setup-0.2.0.exe` 并运行，或在“设置 → 更新”选择“下载并更新”。

验证：124 项测试通过（新增界面外壳、DPI 换算层和 RowList 测试）。用演示数据在 100%、125%、150% 下逐页截图检查。
