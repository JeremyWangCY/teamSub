# TeamSub 0.2.10 发布说明

## 本次修复

1. **彻底消除多槽位碎句合并后的高频假更新（闪烁与「翻译中…」卡死根因）**
   - 当同一条字幕记录跨越多个窗口槽位（即两三行碎句被折进同一条记录）时，旧 `CaptionReader.merge()` 在后续每 0.4 秒轮询中，会先在第一个槽位把记录文本截短回「前半句」并发出 `update`，接着在第二个槽位又改回「整句」并再次发出 `update`。
   - 这导致画面虽无任何变化，界面仍以每秒 5 次的频率重绘该块并不断重置翻译稳定计时器（使译文一直停留在 `翻译中…`，直到第一行滚出 Teams 字幕窗才真正送翻）。
   - 现已改为仅在该记录的最后一个对齐槽位核对完整拼接文本，前序槽位只向下传递最新前缀；画面无变化时零事件、零重绘、不打断在途翻译。

2. **增强带空格及下划线部门后缀的发言人识别（如 `AN Chao_LD Interior`）**
   - `NAME_HINT` 现支持含空格与下划线部门后缀的姓名格式（如 `AN Chao_LD Interior`）。
   - 修复华人常见姓氏拼音（如 `AN` 安、`He` 何、`Yu` 余、`Su` 苏）与英文冠词/代词同形时被句首词表误拦的问题。

3. **同步持久化 `skip` / `fail` 译文状态**
   - 纯数字等无需翻译条目（`tr_status="skip"`）及失败状态在完成判定后立即落盘，避免数据库中残留 `pending`。
