# TeamSub 0.2.11 发布说明

## 本次升级

**从「按姓名格式猜发言人」升级为「直接读取 Teams UIA 树结构与会议参与者」**

1. **按 Teams UIA 树结构原生区分发言人与字幕正文**
   - 不再把 Teams 字幕组拍平成一维字符串列表，而是保留容器层级，从 4 个结构维度直接判定发言人（不再依赖任何姓名格式正则）：
     1. 节点及其父/祖先容器的 `AutomationId` / `ClassName` 语义（`author` / `speaker` / `displayname` vs `caption-text` / `message-body`）；
     2. 独立条目容器（`ListItemControl` / `DataItemControl`）内首个文本为发言人、后续文本为字幕正文；
     3. 头像控件（`ImageControl`）携带的姓名及紧邻的首个文本/子容器；
     4. 同级重复字幕条目容器（每条包含 `[发言人, 正文]`）按位置直接标定角色。
2. **自动读取 Teams 会议窗口参与者列表**
   - 会议中每 30 秒低开销检查一次 Teams 会议窗口中的「参与者 / 人员 / Participants」列表（若已打开），自动同步参会人姓名，无需针对特殊工号、缩写或外部嘉宾命名格式反复打补丁。
3. **保留扁平启发式兜底**
   - 仅当未来或旧版客户端未提供任何容器结构时，才退回 `to_pairs` 局部姓名识别兜底。
