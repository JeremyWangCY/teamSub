# TeamSub 0.2.12 发布说明

## 本次优化与修复

1. **重启/异常恢复直接应用内「续接上次会议」**
   - 当上次会议未正常结束而重启 TeamSub 时，恢复弹窗点击「续接上次会议」会直接把上次的会议数据库接回当前界面继续采集记录，不再调用外部默认程序打开 `.md` 文件。
   - 同步修复 `resume_meeting()` 未初始化 `reader.open_prefix` 导致续接后首帧对齐失效的问题。

2. **清理热路径低效代码与圆点标签变色缺陷**
   - 修复 `transcript_view.py` 按 `dot{i % 40}` 复用圆点标签导致超过 40 条字幕后旧记录圆点变色的问题，改为按色值复用标签。
   - `float_sync`、`update` 与 `tr` 回调改为直接复用索引或末尾倒序查找（O(1) 命中），避免长会议每 120ms 从第 0 条正向线性扫描。
   - 合并单次 `pump()` 批处理内的多次 `float_sync()` 调用，并将 `.md` 快照重写间隔从 `1.0s` 调整为 `4.0s`（SQLite 仍逐批实时落盘），减少 75% 无效磁盘 `fsync`。
