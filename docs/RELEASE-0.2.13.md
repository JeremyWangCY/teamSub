# TeamSub 0.2.13 发布说明

## 本次优化与修复

1. **修复设置页保存主题时清空整场已有译文的隐患**
   - 在「设置 → 主题」修改术语或切换/导入主题并保存时，不再清空当前会议已经完成的全部译文（与主工具栏切换主题保持一致，仅新字幕按新主题翻译；只有切换翻译方向时才会重译）。

2. **界面语义化控件与视觉克制优化**
   - **消除卡片套卡片**：历史会议详情页去掉正文区内层嵌套卡片，改用 1px 细分隔线承接正文。
   - **阅读偏好页升级**：字号（11 / 12 / 14 / 16 / 18）与间距（舒适 / 紧凑）从下拉框改为一键 `Segmented` 分段控件，并新增实时双语排版预览。
   - **导出页升级**：导出范围、格式（Markdown / TXT / SRT）与内容（对照 / 原文 / 译文）改为一键 `Segmented` 分段控件，减少二次点击。
   - 统一等宽数字字体令牌 `UK.F_MONO`，移除未使用的孤立控件引用。

3. **系统提示词与文档同步**
   - 去重翻译系统提示词规则 1/2 中重复的「产品型号」要求，精简 token。
   - 同步更新 `README.md` 功能描述。
