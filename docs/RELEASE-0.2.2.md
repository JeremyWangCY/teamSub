# TeamSub 0.2.2

- 多语种翻译：支持中、英、日、韩、法、德、西、葡、俄、意、阿、泰、越 13 种语言。翻译方向可选「A ⇄ B 互译」（第三种语言译成 A）或「全部译成 X」。语种在本地按文字和常用词判定，提示词按目标语言给出名称与口吻，其余规则、主题、术语表共用。
- 语言和主题下拉改为可搜索的选择器：中文名、本族语名、英文名、代码都能搜，↑↓ 选、回车定。
- 补译前可单独选择这次的翻译方向和主题，不影响实时翻译设置。
- 悬浮窗改为滚动保留最近 40 条，新句在底部，旧句不再立刻清空；往上翻看时不会被新句拽回。

安装：0.2.x 用户可在「设置 → 更新」里直接升级；0.1.x 用户请从本页下载 `TeamSub-Setup-0.2.2.exe` 安装一次。

已知：飞书记录时间取自字幕历史面板，比飞书界面显示的时间晚约 10–20 秒（飞书未对外暴露原始时间）。

验证：130 项测试通过（新增语种判定、方向决策、提示词与搜索选择器测试），冻结程序离线自检通过。
