# TeamSub 0.2.4

- 修复看门狗在窗口从托盘或单实例唤醒后可能出现的循环唤出问题，并确保还原时恢复分层窗口不透明度。
- 修复冻结程序（`TeamSub.exe`）下单实例孤儿进程检测只匹配 `pythonw.exe` 的问题。
- 设置页「思考强度」纳入未保存草稿保护；点击「检测」时使用当前表单填写的连接参数，未保存前不改写磁盘配置。
- 译文质检（QA Check）去掉机械的术语字面匹配，仅保留数字、单位、疑似未翻译与长度异常检查；历史会议补译同步接入质检。
- 修复 `TEAMSUB_DATA_DIR` 环境变量在配置读写与实例 PID 文件上的路径一致性，并校准 `version_info.txt` 版本元数据自检。

安装：0.2.x 用户可在「设置 → 更新」里直接升级；0.1.x 用户请从本页下载 `TeamSub-Setup-0.2.4.exe` 安装一次。

验证：136 项测试通过，冻结程序离线自检通过。
