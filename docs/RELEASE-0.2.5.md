# TeamSub 0.2.5

- 修复悬浮窗与主窗口之间的状态同步：最小化或收进托盘自动切换悬浮窗时不再污染持久配置，还原主窗口后开关状态立即归位，再次点击「悬浮字幕窗」即可直接打开。
- 修复主窗口收进托盘并关闭悬浮窗时未清除托盘/遮罩标记导致主窗口仍处于透明的问题；开启「最小化时切到悬浮窗」后点击标题栏 `✕` 收进托盘也会自动显示悬浮窗。
- 修复高分屏（125%/150%/200% DPI）下悬浮窗滚动区域视口高度被重复换算导致滚动条过早出现的问题。
- 切换深浅色主题、字号重绘或收起再打开悬浮窗时，保留用户拖拽后的屏幕位置。

安装：0.2.x 用户可在「设置 → 更新」里直接升级；0.1.x 用户请从本页下载 `TeamSub-Setup-0.2.5.exe` 安装一次。

验证：139 项测试通过，冻结程序离线自检通过。
