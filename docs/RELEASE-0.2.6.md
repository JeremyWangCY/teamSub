# TeamSub 0.2.6

- **免 GitHub API 限流检查更新**：当 `api.github.com` 因共享出口 IP 或代理触发匿名请求限流（HTTP 403/429）时，自动回退至 GitHub Release 页面跳转与 `SHA256SUMS.txt` 校验解析最新安装包，仍可一键自动下载、校验并更新重启。
- 含 v0.2.5 的悬浮窗状态同步、托盘收放联动、高分屏滚动高度修复与拖拽位置保留等全部改进。

安装：0.2.x 用户可在「设置 → 更新」里直接升级；0.1.x 用户请从本页下载 `TeamSub-Setup-0.2.6.exe` 安装一次。

验证：140 项测试通过，冻结程序离线自检通过，实网 API 限流回退探测通过。
