# TeamSub 0.2.8

- **主题 JSON 导入与导出**（「设置 → 主题」工具栏新增「导入」「导出」按钮）：
  - **导出**：将当前选中主题导出为结构清晰的 `.json` 文件（含 `name`、`brief`、`glossary` 列表），可直接发给 AI 让其照着格式编写新领域的主题与术语表；
  - **导入**：支持导入单个主题 JSON、多个主题数组 `[{...}, ...]`，兼容 AI 常见的输出变体（如自带 ```` ```json ```` 代码块、`glossary` 写成数组 `["a=b"]`、字典 `{"a": "b"}` 或冒号分隔 `"a: b"`）；遇到同名主题时提示选择覆盖或作为新主题导入。

安装：0.2.x 用户可在「设置 → 更新」里直接升级；0.1.x 用户请从本页下载 `TeamSub-Setup-0.2.8.exe` 安装一次。

验证：142 项测试通过，冻结程序离线自检通过。
