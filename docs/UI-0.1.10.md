# 0.1.10：当前翻译主题常驻与直接选择

主界面搜索栏中间新增「翻译主题」下拉框，持续显示已保存的主题；选中即保存并生效。保存失败恢复原选项及运行配置。切换前处理设置草稿的放弃确认，避免之后保存旧草稿覆盖主题。

切换时正在运行的实时翻译服务使用新配置重启，旧请求结果失效，已完成的译文保留；翻译关闭时不自动开启。设置页保存主题后同步选择器，浏览未保存的主题显示「待切换 · 保存后生效」，底部持续显示当前主题。

名称重复时用主题 ID 区分；长名称省略显示，悬停或键盘聚焦显示全称；主题不可用时明确标注，可在下拉中修正。支持浅色、暗色及 1000×640 最小窗口。

译名对照原理：OpenAICompatProvider._sys_prompt 将 Config.topic_instruction() 与 Config.glossary_pairs() 放入 system 提示词，每次 translate 请求随原文和可选上文发送。对照优先采用，允许句意消歧。DeepL、Azure 当前适配器未接入此上下文，主题页明确标注译名对照适用于 OpenAI 兼容引擎。

验证使用临时配置、禁用真实字幕采集，仅允许本机 mock 服务；新增 test_active_topic.py 验证常驻显示、真实下拉点击、保存回滚、设置草稿隔离、切换服务、长名、同名、暗色、最小窗口和配置持久化。
