## 实际改动

- 浅色使用 #F5F5F3 / #FCFCFB，暗色使用 #151515 / #1A1A19 / #20201E；移除应用主题中的纯黑色。主卡片取消默认描边，通过表面明度和留白分层。
- 单行输入、多行输入、搜索和下拉控件使用统一的中性色内嵌双环聚焦效果。保留原生 Entry/Text，中文输入、光标和选区不受自绘样式接管。
- 暗色标题、姓名和悬浮译文采用常规字重。切换主题时按原分配顺序切换发言人色板，连接状态也使用当前主题颜色。
- 自绘按钮、分段控件、模式切换、开关补齐可见键盘焦点；按钮按下后移出再松开会取消触发。
- 配置名称按实际字体宽度省略，完整名称仍保存在配置中；弹出列表跟随控件的实际宽度，支持方向键和回车，关闭后返回原焦点。点击列表外不会误选同高度的选项，空选项列表也不会崩溃。
- API Key 输入增加显示／隐藏，切换配置或重新填入值后恢复遮罩，保留原有加密存储。
- 复制提示增加对勾，2.35 秒保持后用 150 毫秒淡出。最新提示会取消旧计时器，统计文本继续独立更新，避免旧提示恢复过期统计。
- 「复制最近 N 条」反馈显示实际复制条数，而非始终声称复制了 N 条。
- 拖动滚动条、点击轨道或使用键盘翻阅时停止自动跟随；回到底部后恢复。缩短的滚动条不会溢出轨道；内容可全部显示时，校正 Tk 延后的范围回调，去掉残留长灰线。
- 时间、发言条数和用量数值使用等宽数字字体。搜索图标采用固定线条与位置，Esc 清空搜索并保留输入焦点。
- 悬浮窗保留图 2 的四角、线条操作、原文／译文分隔，超长内容采用同套细滚动条；最小宽度下对发言人姓名按像素省略，保住时间和关闭按钮。
- 继续包含 0.1.8 的窗口语义：关闭到托盘、最小化到任务栏；真正退出在托盘和更多菜单。托盘不可用时回退到任务栏。

## 十条规则的适用性

| 规则 | 本轮处理 |
| --- | --- |
| 1. 微明度分层，禁纯黑 | 已用于应用主题与默认卡片；悬浮窗保留参考图的细边界，Windows 系统标题栏由系统绘制。 |
| 2. 输入聚焦双环 | 通过 Canvas 的两层内嵌抗锯齿路径模拟双环，不添加原生 outline。 |
| 3. 暗色字重降低 40 | Tk 只支持 normal/bold，采用常规字重减轻光学重量；不声称实现精确 360。 |
| 4. 单字 90ms 模糊、30ms 错开 | 当前 Tk 原生文字不支持 CSS blur。字幕保持即时插入，不追加逐字等待或用截图替代可选中的文字。 |
| 5. 图标基线对齐 | 搜索和悬浮窗操作用固定线条绘制并居中对齐；不套用不适用的 CSS em 属性。 |
| 6. 数字防抖 | 时间、条数、用量改用 Consolas 等宽数字。 |
| 7. Grid 0fr 到 1fr 折叠 | 当前设置用页签和 Tk 原生 grid 分配高度；没有新增需要折叠的区块，不为动效添加多余容器。 |
| 8. 防孤字 | 正文保留原生按词换行，悬浮字幕随宽度自适应换行；Tk 不支持 text-wrap:pretty，不改动原文数据强插空格。 |
| 9. 拖拽零回弹，对勾微弹 | 拖动直接跟手、零回弹；不伪称原生窗口使用了 1200/80 的弹簧引擎。复制对勾采用淡出反馈，没有新增点赞功能。 |
| 10. 反馈自熄 | 复制对勾与提示约 2.5 秒后消失；连续操作的旧计时器不会覆盖新反馈。 |

## 视觉与交互验收

这是现有设计系统内的细节优化，以用户提供的悬浮窗图 2 和改动前真实窗口作为参考，没有生成替代性的产品概念图。

界面是 Windows/Tk 原生窗口，不存在可用的 Browser/IAB 页面或 DOM。采用隔离测试数据、禁用采集线程、限制网络到本机，使用 Win32 PrintWindow 只截取测试创建的窗口，并用 view_image 直接查看前后图片。没有截取真实会议或读取用户密钥。

核对客户端 1280×820 与最小窗口 1000×640、浅色／暗色、输入聚焦、展开列表和悬浮窗。

| 核对点 | 修改前 | 修改后与验证 |
| --- | --- | --- |
| 页面结构与可见文案 | 实时会议、历史会议、设置、帮助，标题区与阅读区分离 | 保持相同区域与顺序；新增密钥显示／隐藏属于明确的可操作改动，没有增加营销文案。 |
| 表面与配色 | 暖色偏黄，多个卡片有细框，暗色阴影为纯黑 | 使用指定中性色、默认无描边卡片；真实明暗截图核对。 |
| 排版与数字 | 明暗主题都加粗姓名，用量和条数使用比例字体 | 暗色使用常规字重，数字对齐；截图与原生字体检查共同验证。 |
| 输入与下拉 | 蓝色单环，弹层按配置宽度绘制，长名称可能撞箭头 | 双环聚焦、实际宽度弹层、名称省略、方向键／回车／Esc／外部点击验证。 |
| 阅读与滚动 | 滚动条操作未同步跟随状态，短内容可残留长灰线 | 保住阅读位置、回到底部恢复跟随、内容放下时不显示滑块；新增回归复现并验证。 |
| 悬浮窗 | 已有四角修复与图 2 的信息层级 | 延续同一参考，统一明暗主题与细滚动条；300px 宽的长姓名不挡操作。 |
| 短反馈 | 多个定时器可能互相覆盖，统计可能恢复成旧值 | 独立提示层，最新计时器，2.5 秒淡出；使用真实事件循环验证。 |

新增专项脚本 test_design_details.py 覆盖长名称、下拉键盘、外部点击、密钥遮罩、按钮拖出取消、搜索 Esc、反馈计时、主题色迁移、暂停状态、滚动位置和悬浮窗最小宽度。完整回归结果、真实窗口截图和可执行文件随本次输出保存。

上述原生框架差异为明确保留的实现边界；不将 CSS 模糊、可变字体精确字重或 Web Grid 动画标记为已完成。
